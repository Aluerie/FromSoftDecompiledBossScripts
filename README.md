# 🐉 Elden-Ring-Decompiled-Boss-Scripts

Decompiled Lua AI scripts for Elden Ring bosses.

## 📂 Layout

| Folder | Contents |
| --- | --- |
| [`Base Game`](Base%20Game) | Base game bosses |
| [`Shadow of the Erdtree`](Shadow%20of%20the%20Erdtree) | DLC bosses |

Files are named `<Boss Name> - <ID>_battle.lua`, where `<ID>_battle` is the script's original name in the game files. Bosses with several names or phases that share one script are joined with `&`, e.g. `Malenia, Blade of Miquella & Malenia, Goddess of Rot - 212000_battle.lua`.

## 🤝 Contributing

All kinds of contributions are welcome:

* Boss scripts you've decompiled yourself. Open a PR, it saves me the time of decompiling them.
* Helpful comments in the `.lua` files.
* Boss flowcharts.
